# Fazenda Viva

Protótipo jogável inicial de um jogo de fazenda social para navegador.

## O que já funciona
- Seis canteiros selecionáveis.
- Plantar cenouras usando sementes e moedas.
- Crescimento temporizado de 30 segundos.
- Colheita que entrega cenoura e moedas.
- Limpeza de canteiro.
- Salvamento local automático no navegador.

## Como testar
Abra o projeto por um servidor web. Para publicar como demonstração, habilite GitHub Pages nas configurações do repositório, usando a branch `main` e a pasta `/(root)`.

O jogo usa Phaser 3.90.0 via CDN. É necessário estar conectado à internet para carregar a biblioteca.
